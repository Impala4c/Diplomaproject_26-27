Проверены также стабильность между повторными запусками сканера и отдельными процессами CLI, разные fingerprint у разных мест находок, сохранение отпечатка старого появления после добавления коммита и вход SHA-256 без исходных значений. ## Стабильный fingerprint: шаг 2

Сканер версии `0.2.0`, схема отчёта `2.0`. Два отдельных запуска CLI на сохранённом репозитории дали побайтово одинаковый JSON и одинаковый fingerprint:

```text
fa6597db909e32fc4daba32e56013d1bfa8f29812ddec101133e659e69d57645
```

Он вычислен как SHA-256 канонического JSON из схемы `location-v1`, пути `.env`, полного OID коммита добавления, строк 2–3 и маскированных компонентов. Исходные значения и контекст в хеш не входят. Этот идентификатор описывает место находки; его нельзя использовать для поиска одного секретного значения в разных местах.

Ожидание изменилось: раньше отпечаток менялся между запусками, теперь остаётся одинаковым при неизменных данных. Число находок в этой демонстрации осталось равным 1. В других историях одна пара, сохранённая в нескольких коммитах, теперь имеет отдельную запись и fingerprint на каждое появление; чтение одинакового blob не повторяется.

Проверка в PowerShell из корня проекта без создания файлов:

```powershell
$first = python -B scripts/scan_history.py tests/synthetic_histories/generated/aws_pair_demo | ConvertFrom-Json
$second = python -B scripts/scan_history.py tests/synthetic_histories/generated/aws_pair_demo | ConvertFrom-Json
$first.candidates[0].fingerprint -eq $second.candidates[0].fingerprint
```

Ожидается `True`. Оба запуска сканера возвращают код `1`, потому что нашли кандидата. Пересоздание Git-истории может изменить commit OID и fingerprint; для этой проверки нужно использовать существующую историю.

Артефакты: [JSON](aws_pair_demo.json), [CSV](aws_pair_demo.csv), [manifest](../data/manifests/aws_pair_demo.json).

Это функциональная проверка на искусственных данных. Она не измеряет precision/recall на независимом корпусе, не подтверждает превосходство над baseline и не является результатом ML-обучения.
