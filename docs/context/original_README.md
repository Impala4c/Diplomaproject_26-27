# Архитектура и подготовка к первой предзащите

В одном архиве собраны результаты двух последних содержательных запросов.

## Основные файлы

- [architecture.md](../architecture.md) — полная архитектура дипломного проекта: 22 раздела, схемы Mermaid, компоненты, данные, обучение, оценка, безопасность, структура кода и диплома. Файл сохранён без изменений.
- [predefense_readiness.md](../planning/predefense_readiness.md) — предыдущий разбор по семи критериям первой предзащиты: что подготовлено, чего не хватает и что нужно согласовать. Ответ перенесён из чата; ссылки адаптированы к содержимому архива.

## Исходные материалы

Для чтения ссылок приложены `roadmap 1.pdf`, `read.me`, `req.md`, `ref.md`, `repo.md`, `examples_leaks.md` и папка `12-15_october_research/`.

Исходные документы скопированы без редактирования. Несогласованности сроков и старые упоминания третьего участника не исправлялись при архивировании. Актуальный состав команды — два автора.

Разбор предзащиты предшествует архитектурному документу. Документы описывают план и предложения; архивирование не подтверждает наличие реализованного кода, обученной модели или измеренных результатов.
